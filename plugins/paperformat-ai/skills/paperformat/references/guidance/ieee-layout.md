# Review IEEE layout

Keep title, author, affiliation, abstract, and keyword front matter full width
unless the target template proves otherwise. Start the two-column body at the
first confirmed body heading, normally after keywords.

Use continuous section breaks for a same-page transition. Verify the section
type on the following section, column count, spacing, margins, and page size.

Flag wide tables, figures, equations, merged cells, fields, floating drawings,
and existing complex sections before conversion. Do not shrink, move, or
rebuild them without a typed supported operation and explicit approval.

After conversion, compare every page for title loss, incorrect body start,
indent regression, extra blank pages, clipping, and changed object geometry.
