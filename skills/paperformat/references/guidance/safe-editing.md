# Plan safe edits

Prefer the smallest exact scope that resolves a confirmed issue. Keep one table
or one semantic element isolated from other instances.

Use Safe only for allow-listed formatting with a known target value and stable
location. Use Review for page geometry, sections, columns, broad style mapping,
or operations likely to change pagination. Use Experimental for unsupported or
ambiguous structure.

Never authorize body-text replacement, equation XML changes, citation-field
rewrites, image-media changes, table geometry, macros, or embedded objects.

Rebuild every attempt from the immutable original. Treat rollback as discarding
the candidate, not reverse-editing it.
