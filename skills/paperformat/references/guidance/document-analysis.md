# Analyze a manuscript

Use both structural evidence and rendered pages. Prefer confirmed Word style,
text pattern, effective formatting, position, and neighboring-context evidence
over any single signal.

Treat low-confidence classifications as unresolved. Ask for confirmation when
the semantic role changes the target rule or layout boundary.

Protect these roles explicitly: title, authors, affiliations, abstract,
keywords, headings, body, captions, references, equations, and tables. Never
infer a writable OOXML location from visible text alone.
